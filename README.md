## Description

### Situation
CEVA Shipping company provided us with available delivery Zip codes from two of our three company warehouses, AZ and TX.
Co-owner wanted to visually understand where CEVA could ship from when using 2 and 3 day transit shipping options.

### Task
Develop an interactive dashboard to visualize delivery zip codes by transit time (2-day and 3-day) for AZ and TX warehouses, enabling efficient updates to shipping templates on Amazon, Walmart, and Newegg.

### Action
- Download US zip codes mapped to longitude and latitude coordinates
- Download CEVA zip code file
- Map zip codes to longitude and latitude coordinates
- Generate four interactive maps in Streamlit, displaying 2-day and 3-day transit zones for AZ and TX warehouses.

### Result
Updated shipping templates on Marketplaces to use CEVA shipping when other Freight shipping methods were more expensive or out of delivery range.
